# Nikhileswar Behera — Portfolio Website

A premium, interactive personal portfolio website showcasing my work, projects, skills, and journey as a developer. Built with **React.js**, **Framer Motion**, **Lucide Icons**, and custom CSS design systems.

Features a performance-optimized global **interactive pointer-tracking radial glow background** with glossy grid alignments and frosted glassmorphic cards.

---

## Technical Features

* **Interactive Pointer-Tracking Glow**: Dynamic mouse spotlight trail using frame-rate interpolated spring lag animations.
* **Premium Glassmorphic Design System**: Modern color palette featuring custom Amethyst Violet and Electric Indigo glows, with frosted translucent layout cards.
* **Skill Network Showcase**: Floating skill node network with dynamic boundary collision simulations and interactive hover physics.
* **Projects & Certifications**: Visual displays of academic internships, IoT edge-computing models, and machine learning architectures.
* **Responsive Layouts**: Designed to be responsive, mobile-friendly, and accessible across devices.
* **Functional Contact Form**: Direct server-less emailing using configured EmailJS endpoints.

## Setup & Local Development

To run this project locally:

### 1. Clone the repository
```bash
git clone https://github.com/nikhileswarb7-dotcom/nikhileswar-portfolio.git
cd nikhileswar-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env` file in the root directory and configure your EmailJS API credentials:
```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

### 4. Run development server
```bash
npm run dev
```

The application will launch locally at `http://localhost:5173/`.
